# Bounded scientific-semantic evaluation

These are synthetic maintenance cases, not papers, formal research runs or a
scientific benchmark. Passing unit tests cannot establish that an agent reasons
correctly about evidence.

Read `cases.md` with the relevant Skills and answer without network access or other
materials. Save responses and evaluator notes outside public source. Withhold
`rubric.md` until evaluation. Record agent/model, source commit or working-tree
state, cases, actual answers, disagreements and repairs. Multiple agreeing agents
do not establish independent experimental replication.

The three cases exercise evidence -> opportunity decision -> presentation wording,
standard reading with an unresolved upload grant, and reuse of a prior grant
despite hostile instructions in source content. No production pipeline, formal
Mapper initializer or real service is invoked.

The rubric is an answer key for invented facts, not a universal scientific quality
metric. The technical chain is separately covered by canonical, Mapper API,
presentation, lookup and plotting regressions.
