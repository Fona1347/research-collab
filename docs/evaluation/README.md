# Bounded scientific-semantic evaluation

These are synthetic maintenance cases, not papers, formal research runs or a
scientific benchmark. Passing unit tests cannot establish that an agent reasons
correctly about evidence.

Read `cases.md` with the relevant Skills and answer without network access or other
materials. Save responses and evaluator notes outside public source. Withhold
`rubric.md` until evaluation when an authorized separate evaluator is available.
For same-agent review, disclose that limitation and do not claim a blinded test.
Record agent/model, source commit or working-tree state, cases, actual answers,
disagreements and repairs. Multiple agreeing agents do not establish independent
experimental replication.

Cases A–C exercise evidence -> opportunity decision -> presentation wording,
standard reading with an unresolved upload grant, and reuse of a prior grant
despite hostile instructions in source content. Cases D–F exercise explanatory
writing and detail selection for experimental, theoretical and qualitative
arguments: background and prior-work gaps, method rationale, consequential
equations, exhibit roles and selective emphasis, including a continuation of an
existing run. Judge whether the reasoning is sufficiently developed, not whether
the response is shortest. They supply bounded
packets, not full-paper substitutes: do not claim actual source reading, visual QA
or a complete deep-reading run from them. No production pipeline, formal Mapper
initializer or real service is invoked.

The rubric is an answer key for invented facts, not a universal scientific quality
metric. The technical chain is separately covered by canonical, Mapper API,
presentation, lookup and plotting regressions.
