# Research Collab v2.0.0

Research Collab 首个集合 Release，承接原 Paper Collab V1.2.1，将 9 个科研 Skill 的维护源码、测试和分发流程统一到一个仓库。集合版本不替代各 Skill 或证据 schema 的独立版本。

## 包含的能力

- 阅读与汇报：`paper-deep-reading`、`paper-presentation`、`zotero-literature-note`。
- 检索与研究方向：`research-lookup-enhanced`、`sciverse-research`、`research-opportunity-mapper`、`research-opportunity-mapper-quick`。
- 科研绘图与全文获取：`sci-plot`、`literature-fulltext-acquisition`；全文获取适配器仍为**实验项**。

## 主要变化

- 提供统一的校验、单包/全包打包、安装、差异检查和恢复入口。新包采用明确的逐 Skill 分发清单；安装保留本地配置与未知文件，遇到漂移暂停对应组件，恢复校验原目标与文件归属。
- 中英文 README 增加最简上手、推荐配置和可复制给其他 agent 的一段式安装提示词。
- 修复 MinerU 缓存对输入文件的绑定，拒绝旧输入或无法核验的缓存；加强公共 HTTP 请求、DNS、重定向及跨域凭据边界。
- Sci-Plot 更新至 0.2.1：子图样式在创建坐标轴时生效，导出保留字体，验证与渲染共享柱状图/热图的数据约束。
- Quick Mapper 一次读取任务日期并支持显式日期；Presentation 增加只读交接检查；默认测试接通同仓库 canonical API，并加入离线 CI。
- 九个 Skill 明确外部材料与指令的边界。完整阅读质量要求与文件上传、Zotero 库范围授权分开，已有明确授权可复用。

## 兼容与升级

Skill 名称、显式调用方式和 `.paper-collab.yaml` 保持不变。完整 Mapper 为 2.2.0 / schema 2.0，Quick 仍为 schema 1.2；普通检索不会自动启动 Mapper。保留零候选、零 eligible pilot、路线与阶段区分、三门及 Unknown、来源独立性、科学反证和读者报告与台账一致性约束。旧格式继续可读。

已有用户建议在维护克隆中切换到 `v2.0.0`，先预览再安装；将目标路径换成自己的项目目录：

```powershell
git fetch --tags
git switch --detach v2.0.0
python scripts/skills.py install --skills-root "D:/research-project/.agents/skills" --dry-run
python scripts/skills.py install --skills-root "D:/research-project/.agents/skills"
python scripts/skills.py check --skills-root "D:/research-project/.agents/skills"
```

只更新一个 Skill 时，为三条 Python 命令都加 `--skill <skill-name>`。存在用户修改时按维护指南核对，不强制覆盖。旧备份恢复现在需要显式指定原来的 `--skills-root`。

## 下载与验证

- `research-collab-v2.0.0-all-skills.zip`：全部九个 Skill 的运行包。
- `<skill-name>-research-collab-v2.0.0.zip`：单个 Skill 的运行包。
- `SHA256SUMS.txt`：分发包校验值。每个 ZIP 还含来源提交与逐文件哈希清单。
- GitHub 自动生成的 Source code 包包含仓库维护工具；Skill 运行 ZIP 不包含集合安装器。需要安装器时使用本标签的仓库源码。

发布依据包括三方独立审计、离线组件回归、隔离安装/打包验证及有限的合成语义检查。CI 配置覆盖 Ubuntu/Python 3.11 与 Windows/Python 3.14；具体执行结果见本 Release 对应提交的 Actions。缺少历史私有材料、平台文件链接权限或外部服务配置的检查会明确跳过，不计作线上验证成功。

## 已知限制

安装 Skill 不会安装依赖、注册 MCP 或授权上传。Sciverse、MinerU、Zotero 等实时功能需要各自的运行时、凭据与适当授权；本次发布未开展真实文献检索或论文下载。全文获取适配器当前依赖 Windows 与 PowerShell 7。结构检查和离线测试不能证明科学结论正确，有限语义小样例也不是通用质量基准。
