# 从真实文献发现值得写的主张

用于研究展望、基于文库找观点，或用户明确询问前沿进展。根据受众和用途决定贡献的含义。综述可以重新解释读者熟悉的结果。研究展望还应指出相对已检工作的增量，以及据此值得改变的实验或设计选择。

## 从观察出发

先从用户的疑问、专业直觉或论文中的具体结果建立一个可检验的问题。没有预设方向时，在授权的文库中检索不同机制、材料、指标和同义术语，留意结果间的张力、方法边界与代价。有两项反向结果时先核对体系、刺激、测量和尺度是否可比。保留带来新解释的连接，也保留足以改变它的不利数据。

对承担关键推断的来源近读正文。留下作者、年份、DOI 或文库条目标识，以及能核对该事实的图、表、章节、卷页或案号。分别记录一手证据（实测/数据/原典档案/制定法判例）、模拟或理论推算、原作者/前人解释，以及你自己的推断与待核查缺口。

**无检索工具或仅摘录降级边界**：只有题录、摘要或少量摘录，且当前无联网/本地全文检索权限时，严禁从记忆补编未提供的 DOI、页码、卷期、图号、档案馆索书号、判例案号或统计数据；只在已提供材料范围内输出工作方案（或史料/文本比勘框架），在研究展望、共同立论或内部审阅场景中单列一份最小待核查清单，标明哪些判断依赖补查原文或扩展检索（正式投稿正文稿除外，不向成品正文插入内部清单）。

## 给已有解释一次胜出的机会

从候选主张反查最接近的已有工作。按研究对象、解决的问题、机制或读出方式选近邻；沿原作术语、对照组、相关引文和允许范围内的后续研究追查。优先用户指定的文库。要求“最新”时核对检索日期与来源覆盖。限定本地时，结论的范围就是已检本地文献。

用原文讲清近邻**已经实现、测得或预测了什么**。再找一个能解释同一观察的替代原因、负结果或对照。若作者已经提出同一主张，把它归还作者。可以转而指出跨文献连接、此前未比较的条件、有不同结果的预测，或承认该方向最适合写成已有工作的综合。

## 形成推荐

较强的主张能让读者复述以下关系：已有解释能覆盖哪项观察，候选增加的视角或机制在什么条件下产生不同预期，这个差别会改变哪项决定。给出一个能区分解释的观察或比勘条件，写明何种结果应转向替代解释。非实验学科改用符合该学科的“解释框架/考辨路径/规范判断”表述，不强套“工作假设/机制推断”词表。大胆假设可沿已知脉络充分展开，把跨度最大的一步标为待核查推断。

有证据排序后，复核最接近的工作和足以改变推荐的反例或对照。完成这两个核对，或已定位只有补实验、查核档案/原文或扩大获准资料范围才能解决的缺口，即可交付。给用户首选和证据，不固定论文配额。若关键差别在现有材料中仍分不清，交付当前最有信息量的比较与明确标出边界的候选方案。

**适用例外（系统综述 / Meta 分析）**：若任务属于 PRISMA 系统综述、Meta 分析或全量实证盘点，不可按“最接近前作与 1 个反例”两个核对即行定稿；必须满足全面检索召回、双人独立筛选、偏倚风险评估（RoB/NOS）与异质性检验。材料未齐时明确说明不可直接交付合并结论，仅推进当前材料支撑的局部准备（如统一已有摘要的口径差异、拟定检索式与纳排/偏倚核查清单）。

蓝方在论点包中保留上述证据位置、作者已有贡献、新推断与改判条件。红方据此复查最影响结论的一步。向用户呈现时将机制、支撑理由和相应验证接在主张下面。只有真的要在不同主线或下一步投入之间取舍时才交给用户选择。
