# Lightweight publication QA

Apply these checks to every delivered figure:

- State the one-sentence conclusion and ensure each panel contributes distinct
  evidence.
- Use the requested final width; 89 mm single-column and 183 mm double-column are
  useful conservative starting points, not universal journal mandates.
- Keep SVG text editable and PDF text as TrueType.
- Use readable sans-serif text, restrained color, non-color redundancy, and no
  rainbow map.
- Record sample size, center, spread, statistical test, correction, and exact
  comparison whenever the figure makes a statistical claim.
- Keep a traceable source-data file and do not modify it during rendering.
- Prefer SVG/PDF for line art. Use PNG as a 300-DPI preview unless a target journal
  requires another value. Verify TIFF mode and resolution.
- Inspect the final-size render for cropped labels, overlap, illegible legends, and
  grayscale ambiguity.

Journal requirements change. Before submission, verify the current official author
guide and research figure guide for the exact target journal. If the local
nature-figure skill is available and a Nature-family audit is requested, use it as an
optional review layer; it is not a Sci Plot runtime dependency.
