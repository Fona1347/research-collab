# Citation Policy

Default citation style is layered citation.

## Main Paper

Always list the main paper in the final note with available fields:

- title,
- authors,
- journal,
- year,
- DOI,
- Zotero item key,
- BibTeX key.

## Normal Citations

Use human-readable citations in prose:

```text
Author et al., Journal Abbrev., Year
```

Add the BibTeX key when it improves traceability:

```text
Author et al., Journal Abbrev., Year [@bibtex_key]
```

## High-Weight Evidence

Use blockquote only for:

- short, traceable source excerpts,
- clearly labeled evidence blocks,
- key passages that the user needs to inspect separately.

Do not use blockquote for ordinary paraphrase or unsupported interpretation.

Keep quotes short and necessary.

## Related Papers

Include related papers only when they are high-weight:

- key background work,
- near-neighbor methods,
- conflicting conclusions,
- directly relevant baselines.

If related papers are mentioned only in weak notes and are not verified, omit them or mark them as unverified.

## User Overrides

Allow user overrides:

- citation-only,
- footnote-style,
- another explicit format.

Do not let citation style override evidence quality rules.
