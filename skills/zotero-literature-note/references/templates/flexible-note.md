# Flexible Note Template

Use this when a standard section layout would distort the paper.

```markdown
# {paper_short_title} 阅读笔记

## 1. 文献信息

- Title:
- Authors:
- Journal / Year:
- DOI:
- Zotero item key:
- BibTeX key:

## 2. 一句话定位

这篇论文是什么类型的工作？它最核心的对象、问题或贡献是什么？

## 3. 核心理解

用短段落说明论文主线。按论文类型自由组织，不强制套用方法/结果/讨论。

## 4. 证据与材料

列出支撑核心理解的关键实验、模型、数据、图表、段落或 annotation。

## 5. 重要细节

根据材料选择小节，例如：

- 模型/公式
- 图表解读
- 方法流程
- 数据集/工具
- 参数与假设
- 用户 annotation 问题

## 6. 贡献、局限与风险

说明什么是强证据支持，什么只是推断或待验证。

## 7. 我的总结 / 后续待读

保留可操作的 follow-up reading 或问题。

## 8. 参考文献

列出主文献和实际使用过的高权重相关文献。
```
